# CodeAlpha E-Commerce Data Analysis

## CodeAlpha Data Analytics Internship

This project was developed as part of the CodeAlpha Data Analytics Internship.

The project focuses on Web Scraping and Exploratory Data Analysis (EDA) using Python.

## Tasks Completed

### Task 1: Web Scraping

Data was collected from a public website using Python.

Libraries used:
- Requests
- BeautifulSoup
- Pandas

The scraped data includes:
- Product Title
- Price
- Rating
- Availability

The collected data was saved as `products.csv`.

### Task 2: Exploratory Data Analysis

The scraped dataset was analysed using Python.

Analysis performed:
- Dataset structure inspection
- Data type analysis
- Missing value checking
- Statistical summary
- Average price calculation
- Average rating calculation
- Highest-priced products identification
- Rating distribution
- Price distribution
- Price vs Rating analysis

## Visualizations

The project generates three visualizations:

1. Product Rating Distribution
2. Product Price Distribution
3. Price vs Rating
